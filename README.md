# YouTube Clone — незавершённый учебный макет

Ранняя заготовка интерфейса видеосервиса. Проект не завершён и не представлен как готовый продукт или полноценный клон YouTube.

Публичное демо приостановлено, проект исключён из основного портфолио. Исходники сохранены для возможной дальнейшей работы.
